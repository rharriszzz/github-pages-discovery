# Public survey methodology checkpoint

The original [research plan](../RESEARCH_PLAN.md) remains authoritative. Current
data is a deliberately selected seven-site research preview. Account types were
recorded from public GitHub metadata; HTML summaries and manual labels are
retained. Keyword matching is an explainable triage baseline, not calibrated
relevance or a census estimate.

No new external sampling/crawling ran during the shared architecture milestone.
Keep targeted and broader discovery cohorts separate in future pilots; validate
site/repository mapping, live status, duplicates and owner type with provenance.
Respect robots, public request budgets and rate-limit responses. Evaluate diverse
high/low ranked examples with explicit false-positive and exclusion denominators
before expansion. Private playlists/history and their inferred graph never feed
public exports automatically.
