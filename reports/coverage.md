# Public coverage checkpoint

Seven researched seed records: five GitHub User accounts and two Organization
accounts. All seven retain `research_preview` status. Zero new sites were crawled
or independently live-validated in this implementation milestone. The 5/7 and
2/7 account counts describe only this selected sample, not GitHub Pages generally.

No 20-site or 100-site pilot has run. Discovery-frame bias, stale summaries,
repository-to-deployment mapping and selective search coverage remain unresolved.
The original offline catalog reproduces unchanged. Private-source coverage is
written only to the local `evidence_coverage.json`, outside this repository.

A later bounded probe examined five public repositories, all with Organization
owners, and independently fetched two selected github.io pages successfully.
These belong to a separate targeted/private review queue; they have not been
merged into the public seven-record catalog or evaluated for user usefulness.
The remaining three project sites were not independently validated by this
crawler. The 20/100-site experiments remain unrun. See the current
[implementation checkpoint](../docs/implementation_status.md) for request/failure
accounting and remaining work. No combined representative ratio is justified.
